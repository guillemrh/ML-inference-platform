## Structure

Each skill directory contains:
- `SKILL.md` - Metadata (name, description) and overview
- Supporting `.md` files - Detailed documentation on specific topics

## How Skills Are Used

1. **Auto-loaded**: Skills are loaded when working on related files
2. **Reference**: Provides standards and patterns to follow
3. **Consistency**: Ensures code follows project conventions
